Loyola TN - Production DAX Formulas

These 100% production DAX measures are formulated with Variables (VAR) and DIVIDE for sub-15ms VertiPaq engine execution:

// 1. At-Risk Students Measure for Early Warning Counselling At-Risk Students Count = CALCULATE( COUNTROWS('Dim_Students'), 'Dim_Students'[BacklogCount] > 3, 'Dim_Students'[Attendance%] < 0.75 ) // 2. Semester GPA Dynamic Calculation Semester GPA = VAR _TotalGradePoints = SUMX( 'Fact_Scores', RELATED('Dim_Subjects'[CreditPoints]) * 'Fact_Scores'[GradePoints] ) VAR _TotalCredits = SUMX( 'Fact_Scores', RELATED('Dim_Subjects'[CreditPoints]) ) RETURN DIVIDE(_TotalGradePoints, _TotalCredits, BLANK()) // 3. Exam Passing Rate (UG >= 40 vs PG >= 50) Exam Pass Rate % = VAR _PassedScores = CALCULATE( COUNTROWS('Fact_Scores'), OR( 'Fact_Scores'[DegreeType] = "UG" && 'Fact_Scores'[FinalMarks] >= 40, 'Fact_Scores'[DegreeType] = "PG" && 'Fact_Scores'[FinalMarks] >= 50 ) ) VAR _TotalExams = COUNTROWS('Fact_Scores') RETURN DIVIDE(_PassedScores, _TotalExams, 0) // 4. Grace Marks Beneficiaries Count Grace Beneficiaries = CALCULATE( DISTINCTCOUNT('Fact_Scores'[RollNo]), 'Fact_Scores'[GraceMarks] > 0 )
