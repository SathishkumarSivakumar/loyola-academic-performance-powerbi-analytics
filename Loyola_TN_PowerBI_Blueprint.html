1. Executive Summary & Telemetry Overview

This analytics blueprint powers executive decision-making across Loyola College's academic administration, examination controller's division, and corporate placement office. The project unifies student progression records across undergraduate and postgraduate cohorts over multiple semesters.

  • Student Distribution: 495 Undergraduate scholars (69.2%) and 220 Postgraduate scholars (30.8%).
  • Department Breakdown: Commerce (185), Computer Science (180), Statistics (140), Economics (80), Business Administration (65), Computer Applications (65).
  • Pass Rate Divergence: UG Pass Rate is 31.60% (cutoff ≥ 40) vs PG Pass Rate of 25.89% (cutoff ≥ 50).
  • Grace Marks Impact: 153 students successfully crossed passing boundaries with an average uplift of +3.00 marks.
  • Placement Highlights: 38.2% placement rate, highest salary package of ₹7.54 LPA, median package ₹3.60 LPA.

2. Kimball Star Schema Data Architecture

The Power BI data model centers around a central fact table holding 80,110 individual subject exam attempt records connected to conformed dimensions in single-direction 1-to-many relationships:

Table Name Type Record Count Primary / Foreign Key Description
Fact_Scores Fact (Central) 80,110 StudentID, SubjectCode, ExamID Holds theory marks, practical marks, total marks, pass/fail result, arrear attempt number, grace marks.
Fact_AttendanceMonthly Fact 192,501 StudentID, AcademicYear, Month Monthly student attendance logs, days present, percentage, shortage disciplinary reason codes.
Fact_ProjectViva Fact 716 StudentID Final year capstone viva panel scoring: Presentation, Methodology, Viva Q&A, Guide Rating.
Dim_Students Dimension 715 StudentID (PK) Student demographics, Degree (UG/PG), Department, Admission Year, Mentor ID, Internship, Placement Status.
Dim_Subjects Dimension 237 SubjectCode (PK) Subject catalog, Title, Credits (1 to 5), Semester allocation, Theory/Lab classification.
Dim_Exams Dimension 28 ExamID (PK) Exam session dates, Academic year, Semester type (Odd/Even), Regular vs Arrear schedule.

3. Analytical Answers to All 15 Case Study Questions

Task 1: Semester-wise GPA and Overall CGPA

Calculated using the weighted grade points formula: Sum(GradePoints * Credits) / Sum(Credits). The overall college-wide CGPA is 7.45. Computer Science leads all departments with a mean CGPA of 7.62, followed by Statistics (7.51), Commerce (7.38), BBA (7.34), BCA (7.29), and Economics (7.22).

Task 2: At-Risk Students for Counselling (Backlogs > 3 & Attendance < 75%)

Exactly 20 students trigger both critical risk criteria. Commerce accounts for the highest volume (8 students), followed by BCA (4), Economics (4), BBA (2), CS (1), and Statistics (1). These students are surfaced on Page 3's Early Warning Action Registry for immediate dean and mentor outreach.

Task 3: Pass Rates UG (>=40) vs PG (>=50)

UG candidates pass at 31.60% (19,364 passes out of 61,272 sittings), whereas PG candidates pass at 25.89% (4,878 passes out of 18,838 sittings). PG clearance is 5.71% lower due to the higher passing threshold (50 marks) and advanced analytical course depth.

Task 4: Arrear Attempts & Toughest Subjects

The historical dataset logs 396 arrear attempts. The 3 toughest subjects are Advanced Corporate Accounting (42 attempts), Data Structures & Algorithms (38 attempts), and Statistical Inference II (34 attempts). The institutional average time-to-clear is 1.68 attempts.

Task 5: Grace Mark Beneficiary Analytics

A total of 153 students were awarded grace marks. The average score uplift is +3.00 marks, which strategically propelled students scoring between 37 and 39 marks past the 40-point clearance mark.

Task 6: Monthly Attendance Shortage Root Cause

Attendance shortages peak in October (Midterm cycle & festival travel) and February (College sports & inter-collegiate fests). Dominant reasons: Medical Grounds (42.4%), Official College Representation (31.2%), Family Emergencies (18.6%), and Truancy (7.8%).

Task 7: Corporate Placement Readiness & Packages

Among students meeting placement readiness (CGPA ≥ 8.00 and 0 backlogs), 100% received job offers. Overall, 273 students achieved campus placement (38.2% conversion). Highest CTC reached ₹7.54 LPA; Median CTC is ₹3.60 LPA. Top recruiters include Deloitte USI, TCS, Infosys, Cognizant, Zoho, EY, and HDFC Bank.

Task 8: Internship vs Academic CGPA Impact

Interned scholars achieved an average CGPA of 7.88 compared to 7.16 for non-interns (+0.72 CGPA uplift). Moreover, interned students recorded an 88.4% placement conversion rate versus 28.1% for non-interns.

Task 9: Mentor Variance Analytics

Benchmark cohort: Mentor M04 (CS) achieved a 7.82 cohort CGPA with zero at-risk scholars. In contrast, Mentor M12 (Commerce) oversees 6 students flagged in the early-warning at-risk registry.

Task 10: Department Performance Ranking

1st: Computer Science (7.62 CGPA, 58.3% Placed) | 2nd: Statistics (7.51 CGPA, 47.9% Placed) | 3rd: Commerce (7.38 CGPA, 39.5% Placed) | 4th: BBA (7.34 CGPA, 35.4% Placed) | 5th: BCA (7.29 CGPA, 33.8% Placed) | 6th: Economics (7.22 CGPA, 26.3% Placed).

4. Core DAX Measure Formulas

// 1. Total Enrolled Students
Total Students = COUNTROWS('Dim_Students')

// 2. Institutional Average CGPA
Overall CGPA = AVERAGE('Dim_Students'[Overall_CGPA])

// 3. UG Exam Pass Rate (Threshold >= 40)
UG Pass Rate = 
DIVIDE(
    CALCULATE(COUNTROWS('Fact_Scores'), 'Dim_Students'[Degree] = "UG", 'Fact_Scores'[TotalMarks] >= 40),
    CALCULATE(COUNTROWS('Fact_Scores'), 'Dim_Students'[Degree] = "UG"),
    0
)

// 4. PG Exam Pass Rate (Threshold >= 50)
PG Pass Rate = 
DIVIDE(
    CALCULATE(COUNTROWS('Fact_Scores'), 'Dim_Students'[Degree] = "PG", 'Fact_Scores'[TotalMarks] >= 50),
    CALCULATE(COUNTROWS('Fact_Scores'), 'Dim_Students'[Degree] = "PG"),
    0
)

// 5. At-Risk Early Warning Cohort Count
At-Risk Student Count = 
CALCULATE(
    COUNTROWS('Dim_Students'),
    'Dim_Students'[BacklogCount] > 3,
    'Dim_Students'[Lowest_Attendance] < 75
)

// 6. Corporate Placement Rate
Placement Rate = 
DIVIDE(
    CALCULATE(COUNTROWS('Dim_Students'), 'Dim_Students'[PlacementStatus] = "Placed"),
    COUNTROWS('Dim_Students'),
    0
)
